# Firmware (QMK userspace)

A QMK userspace for the Halcyon Kyria rev4: `make firmware` builds it against
the pinned Vial QMK checkout in `.deps/vial-qmk`.

- `users/halcyon_modules/` — splitkb's Halcyon module support (display,
  encoder, trackpad), copied unchanged from
  [splitkb/qmk_userspace](https://github.com/splitkb/qmk_userspace) at commit
  `e0900a55dbb08ff5770236dd6129fedacab620e4` (branch `halcyon`).
- `keyboards/splitkb/halcyon/kyria/keymaps/keypress_hlc/` — this project's
  keymap, started from splitkb's `vermoot_hlc`:
  - `keypress_display.c` — both screens, the split sync and the raw HID
    command the computer helper uses;
  - `key_text.h` — what each key shows; `layout_tables.h` — what each key types
    per keyboard language (generated);
  - `smooth_assets.c/h` — every large character, symbol and text font, as
    Quantum Painter images (generated by `tools/generate_smooth.py`);
  - `keymap.json`, `vial.json`, `config.h`, `halcyon_overrides.c`, `rules.mk` —
    layout, Vial definition and build settings. The unlock keys for Vial are
    B + J (`VIAL_UNLOCK_COMBO_*` in `config.h`).
